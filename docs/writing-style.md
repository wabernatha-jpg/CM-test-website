# Writing Style: Copy & Content Rules

This file governs any words Claude drafts or edits for this site: headlines,
body copy, service descriptions, proposal-style pages. It's separate from
the visual rules in `CLAUDE.md`. Read both before touching on-page copy.

Source of truth for brand voice is `Change_Maven_Brand_Guide.md` §06 in the
`EA` repo. This file restates it here since `Website_design` is a separate
repo and can't reference `EA` at runtime. If the two ever drift, the Brand
Guide wins.

## Brand voice

Change Maven's voice is consistent across proposals, website, emails, and
presentations:

- **Conversational but credible**: speak like a trusted advisor, not a
  textbook.
- **Direct and clear**: say what you mean, no jargon or filler.
- **Collaborative**: use "we" and "together" language wherever it fits.
- **Confident without arrogance**: show substance, not self-promotion.

### Tone by context

| Context | Tone |
|---|---|
| Website | Warm, direct, approachable. Speak to the COO worried about a rollout failing. |
| Proposals & formal documents | Professional, precise, outcome-focused. Lead with the client's challenge. |
| Social media | Conversational, insight-driven, never salesy. Share knowledge generously. |
| Emails | Clear and concise. Respect the reader's time. |

### Voice examples

| Context | Say this | Not this |
|---|---|---|
| Website headline | Every change. Fully managed. | Comprehensive organizational transformation solutions. |
| Proposal intro | Here's what we heard from you, and how we'd approach it. | Pursuant to your Request for Proposal dated... |
| Email sign-off | Let me know what questions you have. | Please do not hesitate to contact me should you require further information. |
| Describing services | We coach your team through how to prioritize. | We leverage best-in-class methodologies to optimize change adoption. |

### Words we use

Change, transform, guide, coach, align, together, straightforward, practical.

### Words we avoid

Synergy, leverage, scalable solutions, robust, cutting-edge, best-in-class,
paradigm shift.

## Formatting conventions

This site is entirely public-facing, so the default is the "external" register:
a bit more professional than casual chat, but still human and approachable,
never stiff or corporate.

- Favor scannable structure (short paragraphs, bullets, clear headers) over
  dense blocks of text.
- Never use em dashes.
- Never use "+" or "--" in text.
- Keep sentences direct and concrete. Cut hedging and filler before it ships.

## Visual density

Copy and imagery get planned together, not copy first with images bolted on
after. Default toward heavy visual density (per-point imagery, charts,
diagrams) over long text blocks. See the "Visual Content" section of
`EA/.claude/rules/communication-style.md` for the full rule, which already
governs this repo's sibling one-pagers.
